# DashDrop 🛵📦

DashDrop is a mobile delivery game built with Unity where players ride a scooter through a city, pick up deliveries, and complete orders while exploring an open-world environment.

## Features

* 🛵 Scooter driving system
* 📦 Delivery missions
* 🎮 Mobile joystick controls
* ⏸️ Pause menu
* 🔊 Sound settings
* 🗺️ Open-world city environment
* 📱 Android support

## Built With

* Unity
* C#
* URP (Universal Render Pipeline)

## How to Play

1. Start the game.
2. Accept delivery missions.
3. Ride your scooter to the destination.
4. Complete deliveries and earn rewards.
